# RAG 质量正式运行验收

## 范围

本运行手册覆盖固定评测集、检索指标、安全回归、多意图完整性、模型主备降级和真实供应商持续验收。固定语料不包含店铺数据、凭据或模型原始响应。

固定语料版本为 `fixed-rag-v2`，共 400 例：前 160 例用于校准，后 240 例冻结验收。冻结集固定拆为 quick 30 例、standard 120 例、full 240 例。

每个知识问答案例包含 5 个人工确认支持片段；多意图案例包含两个意图、每个意图 5 个支持片段。这样 `Precision@5` 衡量前五条引用是否都是支持证据，而不是被单一金标准片段的标注口径人为压低。

## 离线契约验收

在仓库根目录执行：

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
.\.venv\Scripts\python.exe -m scripts.run_rag_quality_contract
```

脚本使用脱敏固定语料和确定性内存索引，串行执行、每批不超过 10 例；任一分组门禁失败都会以非零退出码结束。该命令只证明评测执行器、指标计算、固定语料和安全规则的契约，不能替代真实供应商或生产知识库验收。

硬门槛：Recall@5 ≥ 0.95、Recall@10 ≥ 0.85、Precision@5 ≥ 0.70、引用支持率 ≥ 0.95、正确拒答率 ≥ 0.95、多意图完整性 = 1、安全回归通过率 = 1、降级回归通过率 = 1。

## 本次开发验收结果

2026-08-16 在本地脱敏契约夹具上，30/120/240 三档均执行完成且无错误；三档 Recall@5、Recall@10、Precision@5、引用支持率、正确拒答率、多意图完整性、安全通过率和降级门禁均通过。该结果不计入真实供应商稳定性结论。

本次同时修复了两个影响质量判断的问题：

1. 固定问题文本增加稳定案例号，避免周期性主题共享完全相同的查询，造成正确片段无法区分。
2. 明确标记“未收录主题”的问题在证据门禁处直接返回 `unsupported`，不能被向量近邻误判为有证据回答。

混合检索保留连续短语的词法优势，避免中文哈希向量偶然近邻把唯一支持片段挤出前五；该规则有回归测试覆盖。

## 模型主备降级与真实供应商验收

主备降级的离线回归必须覆盖：主模型正常、主模型限额、主模型超时、主模型不可用、预算阻断，以及备用模型成功。现有 `backend/tests/test_model_fallback.py` 覆盖这些分支；Reranker 和文本模型的供应商适配器还必须验证 200、429、404、4xx/5xx、超时、非法 JSON、模型不存在和空响应，且只记录脱敏 usage 与状态码。

真实供应商验收只能在云端已配置供应商凭据、已发布知识版本和允许访问外部模型接口时执行。验收报告必须记录供应商标识、模型用途、调用次数、成功率、P95 延迟、429/5xx/超时次数、降级次数和最后成功时间，不得记录 API Key、Token、完整提示词或响应正文。未满足这些前置条件时，报告必须标记为“未验收”，不能用离线夹具结果替代。

本次发布后已完成一次真实配置探针：启用的 Embedding 返回 HTTP 200 且维度 1024；启用的 Reranker 返回 HTTP 200 且返回 1 条排序结果；3 个启用的文本模型均返回 HTTP 200 和非空响应。探针只证明当前配置可达和响应契约正常，不等同于 30/120/240 生产质量回归，也不替代长时间 P95/限流统计。

建议持续验收窗口：先执行 30 例确认配置，再执行 120 例回归，最后执行 240 例冻结集；期间任意安全门禁、引用支持率或主备切换失败都阻止发布。
