# 受控写入功能状态

本文件记录已落地的 REV 功能证据，不改变需求文档中的范围定义。

## REV-004 幂等命令

`manual_approvals` 使用组织、工作区和幂等键唯一索引。审批创建通过 PostgreSQL `ON CONFLICT ... DO UPDATE ... RETURNING` 原子复用已有审批，重复提交不会生成第二条记录；审批通过响应包含幂等键，便于审计追踪。

验证：`backend/tests/test_postgresql_manual_approvals.py`。

## REV-005～REV-007 价格安全边界

- REV-005：`validate_price_batch` 默认最多 20 个商品，接口 `/v1/review/price-batches/validate` 返回批次总数、限制和逐批校验结果。
- REV-006：价格变化默认不超过 10%；旧价为零时不允许借此绕过限制。
- REV-007：新价格低于 `profit_line_minor` 时批次无效，金额使用最小货币单位整数。

验证：`backend/tests/test_price_batch.py`、`backend/tests/test_price_batch_boundaries.py`。

## REV-008 分项执行结果

执行结果由 `execution_results` PostgreSQL 表按工作区保存，记录批次状态、成功数、失败数和逐项失败原因；新增保存与历史查询 API，前端支持保存 Stub 结果和加载工作区历史。结果只保存脱敏业务消息，不包含凭据或原始上游响应。

验证：`backend/tests/test_postgresql_execution_results.py`、前端 TypeScript 检查通过。

## REV-009 回读核对

回读核对结果由 `readback_verifications` PostgreSQL 表按工作区保存，记录整体是否一致以及每个字段的预期值、实际值和差异状态；新增保存与历史查询 API，前端支持保存和加载回读历史。差异记录不会被后续成功结果覆盖。

验证：`backend/tests/test_postgresql_readback_verifications.py`、前端 TypeScript 检查通过。

## REV-010 全程审计

审计事件由 `audit_events` PostgreSQL 表按工作区追加保存，记录事件类型、业务对象、脱敏详情和发生时间；新增保存与历史查询 API，前端支持记录和查看审计历史。审计记录只追加，不用后续成功状态覆盖差异或失败事件。

验证：`backend/tests/test_postgresql_audit_events.py`、前端 TypeScript 检查通过。

验证：选品决策书领域测试、后端 Ruff/mypy 和前端 TypeScript 检查通过。

## ADS-001 Performance OAuth 凭据持久化

ADS-001 已完成闭环：Performance OAuth 凭据通过独立 PostgreSQL 表按工作区保存，访问令牌和刷新令牌使用现有后端凭据保护器加密后写入；查询接口只返回配置状态、过期时间和隔离标志，不返回任何令牌明文。新增保存与状态查询 API，前端工作区页面支持输入、加密保存、状态展示，并在保存成功后立即清空令牌输入。

凭据写入仍是配置动作，不代表已调用真实 Performance API；真实 OAuth 交换、刷新和报表适配仍需按官方账号权限与接口契约实施。当前验证：领域凭据测试通过、Ruff 通过、前端 TypeScript 通过；API 集成测试因当前运行环境缺少 `cryptography` 包未能收集执行。
