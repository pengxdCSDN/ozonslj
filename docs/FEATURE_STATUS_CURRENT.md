REV-005/REV-006 价格批量校验已增加批次内 SKU 唯一性约束，大小写和首尾空格归一化后重复即拒绝，避免同一批次产生冲突命令。

AI-010 新增通知模板预览 API 和前端入口，仅允许 headline、summary、severity、workspace 等白名单字段；未知字段和敏感字段会被拒绝，预览不会发送外部消息。
