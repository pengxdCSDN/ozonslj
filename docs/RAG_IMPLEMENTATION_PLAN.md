# RAG 详细实施计划

> 状态：PostgreSQL + Chroma 生产运行时已接入并通过聚焦测试；云端真实数据库迁移、Chroma/Worker 健康、备份恢复和真实供应商连通性仍需部署验收。每个工作包只有在代码、测试、文档和验收条件全部满足后才能标记完成。

> 单用户 MVP 约束：首期先完成“配置模型—接入文档—切片发布—混合检索—引用回答/不知道—反馈”闭环。保持接口与数据边界，但不提前建设微服务、多租户、复杂审批、完整模型运营、复杂审计查询或高阶自动化；扩展项只有在核心闭环通过后实施。

## 1. 交付目标

首个可交付能力是“运营知识与数据口径问答助手”：读取受控 Markdown、PostgreSQL 中文注释和 PDF，经过可审核的解析与多策略切片，写入 PostgreSQL 关键词索引与 Chroma 向量索引，并对登录用户提供带来源、可拒答的知识回答。

首期不执行任意 SQL、不查询实时店铺事实、不调用写接口、不接收工作区私有知识，也不让模型自主选择未注册工具。

## 2. 依赖顺序

```text
RAG-1 领域对象与切片内核
  → RAG-2 PostgreSQL 知识治理结构
  → RAG-3 数据源适配、解析与清洗
  → RAG-4 Chroma 与关键词索引
  → RAG-5 意图、重写、召回、融合与精排
  → RAG-6 证据、引用、拒答与回答 API
  → RAG-7 管理预览、反馈与可观测性
  → RAG-8 云端部署、压测与试运行
```

RAG-3 可以在 RAG-2 schema 评审期间使用内存仓库开发，但不得绕过治理表直接写正式 Chroma。RAG-5 可以使用固定 Fake 候选开发，在 RAG-4 对账和撤回测试通过前不得接入线上知识。

## 6. RAG-3：数据接入、解析与清洗

### 实现任务

- 仓库 Markdown 白名单适配器；禁止路径逃逸和 Secret 文件。
- PostgreSQL 系统目录只读导出适配器；只允许固定参数化查询。
- PDF 上传校验、服务器私有持久化卷适配器、不可预测存储键和 Docling 基础设施适配器；领域层只依赖文件存储端口。
- 服务端配置 25 MiB/300 页、单用户单解析任务、70%/85% 容量阈值、普通撤回 30 天清理和每日备份/7 点保留；测试不得把参数写死在领域规则中。
- 部署目标为10 GiB知识卷和2 GiB审计卷；知识卷低于5 GiB禁用 PDF。实现普通删除24小时和安全类15分钟在线/4小时物理清理 SLA、备份删除账本及告警测试。
- 普通 PDF 与 OCR Profile 分离；记录解析器和 OCR 版本。
- 清洗 Unicode、重复页眉页脚和模板噪声，保留表格、代码和版面结构。
- 敏感信息、提示注入、乱码、空白、加密和低 OCR 置信度检测。
- 提示注入检测保存类别、定位和版本；结构化 `EvidenceEnvelope` 隔离证据与系统指令，生成后复检泄密/角色覆盖/工具指令。测试同时覆盖真实攻击与合法安全讨论，检测失败时阻断发布。
- 实现上传隔离、PDF 对象/解压/嵌套限制和脚本/启动动作/附件/外部资源检查；解析运行于无网络、只读输入、非 root、独立临时目录和资源受限沙箱，异常后清理且不放宽重试。
- 定义 `MalwareScanPort` 与 `not_configured/passed/blocked/failed` 契约；首期 2GB 节点不常驻 ClamAV，界面和质量门禁不得把未配置显示为通过。
- 中间产物通过哈希和版本缓存；失败可重试但不覆盖成功结果。
- 缓存仅覆盖非敏感可重建的知识侧产物，键包含全部知识/索引/策略/模型/权限版本；实现撤回、删除、权限和版本变化的主动失效，不缓存用户问题、查询 embedding 或最终答案。

### 退出条件

- 测试 PDF 的阅读顺序、页码、标题和表格结构可核验。
- 加密、损坏、超限、扫描失败和敏感资料全部进入阻断或复核状态。
- 原始文件不能从公开 Nginx 路径访问；API 不返回服务器绝对路径，删除账本能核验私有卷清理结果。

## 11. RAG-8：部署与试运行

### 实现任务

- Chroma 使用固定官方镜像、内部网络、持久卷和初始 256MB 内存限制。

- 实现 `HostFileModelCredentialStore`：项目目录外的宿主机目录 `0700`、随机凭据文件 `0600`、专用服务 UID、同目录临时文件与原子重命名；PostgreSQL 仅保存不透明引用、版本和非敏感掩码。
- 实现凭据创建、轮换、清除、权限/所有者启动检查、文件缺失后的不可用标记和重新录入流程；验证 Nginx、PostgreSQL、Redis、Chroma、业务 Worker、镜像和普通备份均无法获得凭据目录。

- 归一化供应商额度、余额、限流、认证、超时和响应错误，增加用途级熔断、冷却、告警和预审核备用路由；为不同能力编写降级契约测试。
