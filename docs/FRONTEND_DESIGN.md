# ozonslj 前端设计基准

## 设计基准

Web 与 Chrome 插件共用同一套 React 组件、状态和 API 客户端。前端视觉以 `output/playwright/ozon-web-final.png` 展示的深色运营后台为基准，不再维护独立的浅色 Web 主题。

## 视觉语言

- 页面类型：多店铺 Ozon 运营后台。
- 主题：全局深色主题，不在单个页面中切换明暗模式。
- 主强调色：紫色，仅用于当前导航、主要操作、焦点和关键指标。
- 状态色：绿色表示正常，橙色表示低库存，玫红表示缺货或错误。
- 背景：近黑紫色主背景，允许右下角使用克制的蓝绿色环境光。
- 容器：细描边、低对比表面和 9 至 16 像素圆角；禁止通用白色卡片。
- 图标：统一使用 Phosphor Icons。

## 响应式规则

- Web（宽度不小于 900px）：使用 260 至 276 像素固定左侧导航，右侧为十二列内容网格。
- 桌面内容画布最大宽度为 1420 像素；超宽屏增加外侧留白，不横向拉伸指标卡和商品行。
- 工作区选择器和退出操作必须归属左侧栏，不允许漂浮在主内容画布上。
- 桌面侧栏底部必须显示当前用户、角色和明确的“退出登录”按钮；禁止通过 `fixed` 定位模拟侧栏底部区域。
- 桌面侧栏顶部固定分为三行：74 像素品牌区、54 像素工作区选择区、剩余高度导航区；三者必须是独立网格项，禁止通过负边距跨行。
- Chrome 侧边栏及窄屏 Web：顶部品牌栏、工作区选择器和紧凑标签导航。
- 两端使用同一 DOM，不通过复制页面实现响应式布局。
- 所有页面必须在 320px 宽度下可操作，并在桌面宽度下保持最大 1440px 内容范围。

## 功能与设计边界

- 页面数据必须来自当前登录用户有权访问的 PostgreSQL 工作区，不使用视觉稿中的演示数据替代真实接口。
- 登录、退出、会话恢复、工作区权限、加载、空状态、错误和重试状态必须使用同一设计语言。
- 新功能优先复用现有设计令牌和组件；新增颜色、圆角或阴影前应先更新本文档。
- Web 构建使用同源 `/api`；Chrome 插件使用构建时配置的 API 地址和 `chrome.storage`。
