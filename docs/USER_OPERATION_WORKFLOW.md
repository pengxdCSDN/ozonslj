# ozonslj 用户操作流程

> 版本：2026-08-20  
> 适用范围：当前 Web/Chrome 侧边栏中的全部业务页面。  
> 安全原则：Client ID、Client Secret、Api-Key、Access Token 和模型 API Key 只在页面对应输入框中操作，不写入本文档、截图、工单或聊天记录。

## 一、首次进入与工作区准备

1. 登录系统，确认左上角显示正确的店铺工作区。
2. 进入“店铺”，确认当前店铺名称和状态。
3. 进入“系统工具 → Seller 数据同步”，确认 Seller 凭据已保存并验证。
4. Seller 凭据未验证时，只能使用独立配置、知识中心和 Performance 配置页面；商品、库存、订单、履约等页面没有可信数据时不要继续分析。

## 二、推荐的完整业务顺序

```text
账号/店铺
  → Seller 凭据验证
  → 数据准备
  → 知识中心（可选）
  → 选品研究
  → 内容增长
  → Performance 凭据与广告分析
  → 运营分析与汇总报告
  → 任务、质量和审计复核
```

## 三、基础运营页面

### 1. 总览

进入“总览”查看当前工作区的整体状态、核心指标和待处理事项。总览中的数据依赖已经同步并通过质量检查的业务事实；没有数据时应先返回数据准备或 Seller 数据同步。

### 2. 商品

进入“商品”，查看商品、库存和商品状态。先完成 Seller 数据同步，再使用搜索、库存风险和商品详情等操作；不要把估算或公开采样结果当作 Seller 商品事实。

### 3. 运营

进入“运营”，查看销售、库存、订单、履约等运营事实。先执行对应的 Seller 同步任务，确认任务成功后再做趋势或异常判断。

### 4. 任务

进入“任务”，查看同步、导入、分析和重建任务的状态。失败任务先查看错误摘要和质量问题，再决定重试；不要连续点击造成重复任务。

## 四、数据准备

按以下顺序执行：

1. “数据质量”：点击“开始检查”，处理错误和待处理隔离记录。
2. “搜索词导入”：粘贴或导入 CSV，映射关键词、搜索量、转化率，先预览再提交。重复文件会按指纹复用既有批次。
3. “竞品种子”：录入竞品或商品种子，确认来源、标识和研究范围。
4. “公开采样”：选择采样策略和范围，执行采样并保留估算/公开数据标记。

数据质量问题未处理前，不应把异常结果用于选品、利润或内容决策。

## 五、知识中心

### 1. 知识源管理

1. 新建知识源并填写名称、来源和用途。
2. 导入 Markdown、SQL、TXT 或 PDF 等允许格式。
3. 等待隔离检查、解析、切片和索引任务完成。
4. 检查版本状态、来源引用和质量结果；失败时修复源文件后重试。
5. 需要更新内容时创建新版本，不覆盖已发布版本。

扫描 PDF 在未完成安全检查时会保持隔离状态，不能直接进入检索。

### 2. 知识问答

1. 先确认知识版本已经发布。
2. 输入问题并查看回答中的来源引用。
3. 没有证据时以“无可靠依据”处理，不把模型猜测当作业务事实。

## 六、选品研究

建议顺序为“探索选品 → 选品验证 → 竞争分析 → 利润模型”：

- “探索选品”：使用搜索量、转化率、机会分和覆盖缺口筛选候选。
- “选品验证”：核对候选数据来源、估算标记、约束和风险。
- “竞争分析”：结合竞品种子、公开采样和 Seller 数据比较竞争情况。
- “利润模型”：进入“SKU 利润轨道”，按下列流程完成单品利润测算。

#### SKU 利润轨道操作步骤

1. 选择商品来源。
   - 新品或尚未同步的商品选择“手动新品”。
   - 点击“同步 Ozon 商品”，再选择“Ozon 商品”；可按 SKU、Offer ID、商品名称或类目搜索，并勾选一个或多个商品导入。
2. 填写商品上下文。
   - 手动确认产品名称和 Ozon 类目编号。
   - 每个 SKU 确认 SKU 编号、售价、到岸成本、实重、长、宽、高。
   - Ozon 能提供商品名称、SKU、报价和部分规格时，页面会自动带入；到岸成本和缺失规格必须人工补充。
3. 配置规则与费用。
   - 首次使用时填写或导入类目佣金、广告费率、退货损耗、支付费率、包装费、体积重系数和 FBS 物流分档。
   - “导入物流模板”支持粘贴 CSV，先点击“预览模板”校验，再用于测算。
   - 规则配置完成后，后续商品应优先复用已确认的佣金和物流模板版本；不要每个 SKU 重复维护同一套规则。
4. 运行预计利润测算。
   - 点击“运行利润测算”，系统按实重和体积重较大值计算计费重量。
   - 系统自动匹配物流分档，归集佣金、广告、支付、退货损耗、包装、物流和到岸成本。
   - 结果中查看贡献利润、利润率、盈亏平衡价、物流费用、计费重量和规则追溯信息。
5. 导出结果。
   - 在“SKU 结果”点击“导出 CSV”，保存分 SKU 的预计利润结果。
6. 订单产生后校准实际费用。
   - 在“校准实际费用”选择开始日期和结束日期。
   - 点击“从 Ozon 同步财务”，读取 Ozon 财务只读数据，归一化销售额、佣金、物流和其他费用。
   - 也可以粘贴财务 CSV，点击“预览 CSV 对账”。
   - 将实际费用与预计费用对比，用于校准后续利润判断。

物流模板 CSV 的表头保持英文以保证系统可导入，中文含义如下：`template_id`（物流模板编号）、`fulfillment_type`（履约方式）、`warehouse_id`（仓库编号）、`route_id`（物流线路）、`region_id`（区域）、`version`（版本）、`effective_from/effective_to`（生效/失效日期）、`volumetric_divisor_cm3_per_kg`（体积重系数）、`max_weight_g`（计费重量上限，克）、`base_fee_minor`（基础费用，最小货币单位）、`additional_fee_minor`（超重附加费）、`additional_step_g`（超重计费步长）、`fee_rate_bps`（比例费率基点）、`currency`（币种）和 `source`（来源）。

#### 手动填写与自动赋值边界

| 信息 | 当前处理方式 |
| --- | --- |
| 商品名称、SKU、报价 | Ozon 商品同步后自动带入，也可手动修改 |
| 类目编号、商品规格 | Ozon 有完整数据时自动带入；缺失或异常时人工确认 |
| 到岸成本 | 必须人工填写或批量导入 |
| 类目佣金 | 当前由经营者填写或导入规则；后续可接入费率自动匹配 |
| 广告费、退货损耗、支付费、包装费 | 经营规则，首次配置后复用 |
| 物流模板和 FBS 分档 | 当前人工维护或 CSV 导入，首次配置后复用 |
| 体积重、计费重量、物流费用 | 系统根据规格和物流模板自动计算 |
| 预计利润、利润率、盈亏平衡价 | 系统自动计算 |
| 实际佣金、物流及其他财务费用 | 订单产生后可从 Ozon 财务只读接口同步 |

#### 最少输入原则

日常测算不需要重复填写全部字段。完成一次规则配置后，通常只需要：选择或同步商品、确认 SKU 规格、补充到岸成本，然后运行测算。只有规则未命中、规格缺失、物流重量超出分档或财务数据无法匹配时，系统才要求人工处理。

任何估算结果都要保留假设和来源，不应直接作为真实财务事实。

## 七、内容增长

建议顺序为“关键词策略 → 标题草稿 → 内容风险 → 受控发布”：

1. 在“关键词策略”选择已准备的搜索词和候选商品。
2. 在“标题草稿”生成多个草稿并比较差异。
3. 在“内容风险”检查禁用词、属性缺失和合规风险。
4. 在“受控发布”查看变更预览，确认目标、字段和数量后提交人工审批。
5. 审批前可以取消；审批后只执行明确授权的受控操作，并查看回读和审计结果。

禁止跳过预览、审批、幂等和回读步骤直接批量发布。

## 八、Performance 广告分析

### 1. 配置与验证

1. 进入“系统工具 → Performance 凭据”。
2. 保存 Performance Client ID 和 Client Secret。
3. 点击“获取 Token 并测试连接”。
4. 页面显示 Access Token 已获取、连接状态可用后，才算 OAuth 验证完成。

后端使用 `https://api-performance.ozon.ru`；`performance.ozon.ru` 是网页入口，不是后端 API 地址。文档、日志和截图不得记录密钥或 Token。

### 2. 广告页面

按“广告活动 → 广告指标 → 关键词诊断 → 汇总报告”使用：

- “广告活动”：确认活动、状态和基础结构。
- “广告指标”：同步并查看展示、点击、订单、销售额、花费等只读指标。
- “关键词诊断”：查看关键词表现、异常和否定词建议。
- “汇总报告”：汇总广告、商品、库存和销售事实，核对时间范围与数据来源。

当前流程只允许 OAuth 验证和广告活动/指标只读检查，不自动修改预算、出价或关键词。

## 九、系统工具

- “Performance 凭据”：配置并验证独立 Performance 服务账号。
- “模型供应商”：配置模型供应商连接；API Key 不写入浏览器持久化存储或文档。
- “模型额度”：设置模型预算、用量和告警边界。
- “RAG 评测确认”：查看评测结果，确认质量门禁后再发布知识版本。
- “Seller 数据同步”：创建商品、库存、订单、履约等只读同步任务并跟踪任务状态。
- “Agent 权限”：为 Agent 配置工具权限和高风险操作门禁。
- “外部通知”：配置通知渠道；发送前先使用预览，避免未经确认发送真实通知。

## 十、结束前检查

每次业务操作完成后，依次确认：

1. 任务状态为成功或已明确标记为部分成功。
2. 数据质量没有新增未处理错误。
3. 关键结果能追溯到 Seller、Performance、公开采样或知识源版本。
4. 受控写入有审批、幂等键、回读和审计记录。
5. 没有在日志、截图、导出文件或聊天中留下任何凭据和 Token。
